# 通用阅读与学习种子

> 给第一次建库的人一套够用的起点。它不是分类学作业；真实材料不适合时，以材料为准。

## 推荐节点类型

| 目录 | `type` / `subtype` | 什么算 | 什么不算 |
|---|---|---|---|
| `人物/` | `entity` / `person` | 有明确身份、可持续指向的作者或思想者 | “作者”“读者”这类角色 |
| `著作/` | `entity` / `work` | 一本书、一篇论文、一门课程等可明确指向的作品 | 某次阅读记录、摘录文件 |
| `概念/` | `concept` | 需要用定义说明的术语、框架或方法 | 只出现一次的普通名词 |
| `论点/` | `concept` | 可被支持、反驳或修正的命题 | 原文摘抄本身 |
| `分析/` | `analysis` | 读者基于多条知识形成的综合判断 | 原作者的原始论点 |
| `来源/` | `source` | 一次可追溯的阅读、课程、论文或访谈记录 | 作为研究对象的著作实体 |

默认控制在六类。没有材料前不要继续细分“章节、摘录、金句”等目录。

## 命名

- 人物：使用最常见全名，其他译名进 `aliases`。
- 著作：使用正式中文名或原名，版本信息写正文。
- 概念：用稳定名词短语，不用“关于……的思考”。
- 论点：用可判断真假的短句。
- 来源：`YYYY-MM-DD-材料名-阅读记录`。
- 同一本书可以只有一个“著作”节点，但每次重要阅读可以有独立“来源”页；两者不得混成一页。

## 关系模板

| from | 关系 | to | 含义 |
|---|---|---|---|
| 著作 | `authored_by` | 人物 | 谁创作了这部作品 |
| 著作 | `introduces` | 概念 | 作品系统提出或讲解某概念 |
| 论点 | `proposed_by` | 人物 | 谁提出该命题 |
| 论点 | `supports` | 论点 | 为另一命题提供理由 |
| 论点 | `critiques` | 论点 | 反驳或限定另一命题 |
| 概念 | `part_of` | 概念 | 概念属于更大的框架 |
| 分析 | `references` | 任意节点 | 分析依赖哪些正典节点 |
| 任意节点 | `derived_from` | 来源 | 该知识由哪份材料编译而来 |

只使用材料中真实出现的边。不要为了图谱好看补边。

## 禁混规则

| 容易混淆 | 分开方式 |
|---|---|
| 著作 ≠ 来源 | 著作是长期对象；来源是一次可追溯材料记录 |
| 概念 ≠ 论点 | 概念回答“是什么”；论点回答“是否成立” |
| 原作者论点 ≠ 我的分析 | 前者建论点并溯源，后者进分析页 |
| 摘录 ≠ 知识 | 摘录先留在来源页；只有可复用的定义、论点或关系才晋升节点 |
| 分类 ≠ 节点 | “哲学/管理/技术”等主题标签不单独建页 |

## 首次 ingest 的最小产物

一份普通阅读材料只需：

1. 一个来源页；
2. 0–1 个著作或人物页；
3. 1–3 个真正可复用的概念或论点；
4. 必要关系边；
5. 一段 ingest 日志。

不要在第一次 ingest 就建立完整人物谱系、章节树或书目管理系统。
